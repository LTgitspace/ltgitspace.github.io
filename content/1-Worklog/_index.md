## 12-Week AWS Cloud Internship

Over 12 weeks, I learned and implemented core AWS services, with the first 6 weeks focused on fundamentals and the remaining 6 weeks building a real-world Smoking Cessation Support Platform.

### Weekly Overview:

**[Week 1: AWS Fundamentals](1.1-week1/)** - Introduction to AWS, learned EC2, S3, and basic CLI operations, set up Free Tier account, deployed first static website on S3.

**[Week 2: Core Services & Setup](1.2-week2/)** - Explored EC2, ECS, ECR, VPC, Lambda, Route53, and Docker basics, set up development environment, registered domain.

**[Week 3: Frontend & Backend Integration](1.3-week3/)** - Built Angular app, integrated Cognito authentication, S3 file storage, and Lambda API endpoints with logging.

**[Week 4: Networking Fundamentals](1.4-week4/)** - Created VPC with subnets, configured security groups, set up Application Load Balancer, tested traffic distribution.

**[Week 5: Container Deployment](1.5-week5/)** - Built Docker images, pushed to ECR, deployed with ECS Fargate, configured auto-scaling.

**[Week 6: CI/CD Pipeline](1.6-week6/)** - Set up CodePipeline with GitHub integration, automated Docker builds with CodeBuild, implemented deployment stages.

**[Week 7: Route53 DNS & HTTPS](1.7-week7/)** - Configured custom domain on Route53, obtained SSL/TLS certificates via ACM, secured application with HTTPS on ALB.

**[Week 8: RDS Database Setup](1.8-week8/)** - Created RDS instance for user data storage, configured multi-AZ for reliability, set up backups and security groups.

**[Week 9: NoSQL & Session Storage](1.9-week9/)** - Built DynamoDB tables for session management and user progress tracking, configured indexes for efficient queries.

**[Week 10: S3 Storage & Optimization](1.10-week10/)** - Set up S3 for user achievement badges and document storage, implemented lifecycle policies and encryption for security.

**[Week 11: Monitoring & Notifications](1.11-week11/)** - Created CloudWatch dashboards for platform health, set up alarms for critical metrics, implemented SNS for user notifications.

**[Week 12: Testing & Deployment](1.12-week12/)** - Conducted end-to-end testing of cessation features, performed load testing, deployed production-ready platform.

### Key Learnings

- AWS core services: EC2, S3, RDS, DynamoDB, VPC, IAM, Lambda
- Containerization with Docker and ECS
- Infrastructure as code concepts with CloudFormation basics
- Monitoring and logging best practices
- Cost optimization strategies
