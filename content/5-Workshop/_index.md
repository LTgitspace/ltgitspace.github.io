# Smoking Cessation Support Platform - AWS Workshop

This workshop guides you through building a comprehensive Smoking Cessation Support Platform using AWS services. The platform helps users quit smoking with personalized plans, progress tracking, community support, and AI-powered coaching.

## Platform Features

- **User Management**: Registration, membership packages, and payment processing
- **Smoking Status Tracking**: Record cigarettes, frequency, costs, and patterns
- **Quit Planning**: Create personalized cessation plans with customizable stages
- **Progress Monitoring**: Track smoke-free days, money saved, and health improvements
- **Notifications**: Daily/weekly motivational messages and reminders
- **Achievement Badges**: Earn and share badges for milestones
- **Community Features**: Share achievements, exchange advice with other members
- **AI Coaching**: Consulting roadmaps and advice from AI coaching agents
- **Relapse Handling**: Support for users who relapse during their journey
- **Dashboard & Reports**: View comprehensive statistics and analytics

## Key AWS Services Used

- **EC2**: Virtual servers for application hosting
- **S3**: Object storage for files and static content
- **RDS**: Managed relational database
- **DynamoDB**: NoSQL database for session and user data
- **Lambda**: Serverless compute for backend operations
- **API Gateway**: REST API management
- **VPC**: Network isolation and security
- **CloudFront**: Content delivery network
- **Cognito**: User authentication and management
- **CloudWatch**: Monitoring and logging
- **SNS**: Push notifications
- **CodePipeline**: CI/CD automation
